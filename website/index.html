A lightweight, free .md file viewer/editor for macOS

Tired of opening a heavy IDE just to view a .md file? Here's a lightweight native Markdown viewer and editor for macOS.
Just double-click any .md file in Finder to open it instantly (must set it as your default app for .md files). Read and edit SKILL.md, AGENTS.md, CLAUDE.md, and the Markdown instructions you give your AI tools.

Opens formatted. Press Command-R or Control-R to edit the raw Markdown.

Features

For the files behind your AI workflow.

New in 1.2.0: Choose and save your reading font, with Monaco as the default. Read strikethrough text with refined heading, table, and code spacing. Set nano.md as your default Markdown app from the first-launch prompt. Switch Read/Edit with Command-R or Control-R, with improved undo/redo synchronization. Open the optional Rate nano.md… link from the app menu, and read the plain-English license summary in About.

01

Skills & agent files

Open SKILL.md, AGENTS.md, and CLAUDE.md from Finder. Use Command-R or Control-R to enter Edit near selected text or your scrolled reading position, then save changes to the same file.

02

Small footprint

A small app bundle, free to use. No account or subscription. No network calls. Saves your file exactly as written: same line endings and encoding, no reformatting.

03

Other Markdown, too

README files, project docs, and notes. The same native app for your other .md and .markdown files.

Images appear as text placeholders; code has no syntax highlighting. Markdown support is partial: HTML stays literal, task lists are noninteractive, and relative links and anchors do not navigate. Documents over 1 MiB or beyond complexity limits display as selectable source. Apple Silicon only.
