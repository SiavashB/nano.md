Features

For the files behind your AI workflow.

01

Skills & agent files

Open SKILL.md and AGENTS.md from Finder. Switch between Read and Edit with Control-R, then save changes to the same file.

02

Small footprint

A small app bundle, free to use. No account or subscription.

03

Other Markdown, too

README files, project docs, and notes. The same native app for your other .md and .markdown files.
